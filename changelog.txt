# Changelog

All notable changes to Symphony are documented here. The section for each
version was used as the body of its GitHub Release up to 0.0.1. Releases now
list the commit subjects since the previous release (see `docs/releasing.md`).

## Unreleased

- The Director's Settings gains a Phases group: each run kind's step list, reordered, added
  to, removed from, edited or reset to its default, with a preview of the list the next run
  follows; a step Symphony would refuse says why on its row and isn't saved.
- `symphony.yml` gains `phases.<kind>.steps`, the step list a run follows, with the
  default implementation list when the key is absent (no migration: nothing is renamed);
  `symphony workflow preview --kind` prints it above the prompt.
- Symphony.app runs the plain mix release from its bundle; Burrito, Zig and the
  Xcode SDK shim are gone from the build.

## 0.0.1

- Initial release of the Symphony agent orchestration service.
- Ships self-contained macOS binaries (arm64 and x86_64) built with Burrito.
