# Changelog

All notable changes to Symphony are documented here. The section for each
version was used as the body of its GitHub Release up to 0.0.1. Releases now
list the commit subjects since the previous release (see `docs/releasing.md`).

## Unreleased

- A run's agent steps end the way the agent records them, never on Symphony's guess: a turn that
  forgets is reminded once, then the step fails with a note. An orchestrated step can ask for an
  answer of a given shape (`answer` in `phases`), checked before it passes. A step that needs a
  person's answer pauses with no session and no slot, shows as a question in the Inbox, and the
  answer resumes the run on that step at once, under the same run.
- Settings › Phases edits an orchestrated step's answer fields, each with a name and a type
  (text, number, true or false, list, object): a bad name or a duplicate says why on its row
  and isn't saved, saving writes the step's `answer`, and the preview lists the fields.
- An implementation run walks its step list: Symphony runs the build, checks and tests itself
  between agent turns, with the agent's session closed and its slot free for another ticket; a
  failed step sends the run back to writing the code with the output, a step that hangs twice
  asks a question in the Inbox, and machine steps still run while Symphony is paused.
- The Director's Settings gains a Phases group: each run kind's step list, reordered, added
  to, removed from, edited or reset to its default, with a preview of the list the next run
  follows; a step Symphony would refuse says why on its row and isn't saved.
- `symphony.yml` gains `phases.<kind>.steps`, the step list a run follows, with the
  default implementation list when the key is absent (no migration: nothing is renamed);
  `symphony workflow preview --kind` prints it above the prompt.
- Symphony.app runs the plain mix release from its bundle; Burrito, Zig and the
  Xcode SDK shim are gone from the build.

## 0.0.1

- Initial release of the Symphony agent orchestration service.
- Ships self-contained macOS binaries (arm64 and x86_64) built with Burrito.
