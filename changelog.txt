# Changelog

All notable changes to Symphony are documented here. The section for each
version was used as the body of its GitHub Release up to 0.0.1. Releases now
list the commit subjects since the previous release (see `docs/releasing.md`).

## 0.0.1

- Initial release of the Symphony agent orchestration service.
- Ships self-contained macOS binaries (arm64 and x86_64) built with Burrito.
