# Plan

- **Label:** `plan` (`breakdown`, its older name, is still accepted)
- **Required:** nothing. A plan ticket is never sent back for missing input: what is unclear becomes
  a decision with a recommended default in its review, and the run goes on with the default.
- **Symphony delivers:** the artifacts checked under "Artifacts wanted", then sub-tickets of one PR
  each, reviewed all at once. A plan ticket never opens a PR itself.

Copy everything below the line into the template's description in Linear (see
[README.md](README.md)). Replace each italic hint with your own text.

---

## Vision

_What you want to exist and why. It can be abstract._

## Context

_The domain, the users and the platform._

## Constraints

_Budgets, deadlines, technology, platforms or rules the result must respect._

## Quality bar

_How good is good enough: the standard the result must meet._

## Artifacts wanted

_Check the ones to produce before the split. With none checked, the plan is a plain split into
sub-tickets._

- [ ] Screens
- [ ] Decisions

## Done when

_What the whole must achieve for this plan to be finished._
