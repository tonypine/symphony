# Bug

- **Label:** `type:bug`
- **Required:** Observed, Expected, Steps to reproduce. Symphony sends the ticket back to `Backlog`
  with one comment naming the missing ones when any is absent or empty.
- **Symphony delivers:** a failing test that reproduces the bug, then the fix, in one PR.

Copy everything below the line into the template's description in Linear (see
[README.md](README.md)). Replace each italic hint with your own text.

---
