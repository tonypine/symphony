Kano map

Must-be · any Mac settings window

  • Clear hierarchy: sidebar and detail
  • Fits 1024×768; sheets keep their footer on screen
  • Remembers size, position, selection
  • Empty state; error states with a way out
  • Keyboard: ⌘N, Delete, ↑↓, Return, Esc, Tab
  • VoiceOver labels; status never by color alone
  • Edit and delete, destructive actions confirmed
  • Light and dark appearance
  • Live updates without layout jumps

Must-be · Symphony

  • Every repo's source, remote, route, WORKFLOW.md, fetch, agents
  • Add a local folder or a GitHub URL with its route
  • Edit source, branch, route, gate
  • Disconnect keeps the folder; clone removal only when unused
  • Comments kept in symphony.yml; changes applied by restart
  • WORKFLOW.md set up while adding

Performance

  • Health at a glance
  • Each problem with its fix
  • Key, branch and WORKFLOW.md found from the source
  • Route preview sentence
  • Run time and last activity per agent

Attractive

  • Set up WORKFLOW.md for a connected repo
  • Stop a stuck run from its repo
  • Make Default without disconnecting
  • Gate record next to its mode
  • Open in Finder, GitHub, Linear

Indifferent, not planned

  • Search, reorder, bulk actions, Fetch Now
